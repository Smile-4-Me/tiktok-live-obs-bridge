# TikTok Live OBS Bridge v1.0.1

## Localization update

- Added a complete Turkish dock translation.
- Fixed locale detection so the plugin reads the language currently selected in OBS directly.
- The bundled interface languages are English, German, Spanish, French, Italian, Brazilian Portuguese, Russian, Japanese, and Turkish. Other OBS languages continue to use English.

## Installation

- Close OBS Studio before installing the update.
- Select the same OBS installation folder that you used for v1.0.0.
- Your profiles, account connections, and preferences are preserved.
